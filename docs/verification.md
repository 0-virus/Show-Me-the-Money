# 검증 기록

날짜: 2026-11-06. 호스트: Windows x64. Go 1.27.3, tcell v2.13.10.

## v1.0.2 연결선 및 게이지 간격 수정

- 원인: 한국어 Windows 코드 페이지 949에서 go-runewidth는 선/블록 문자를 2칸으로 계산하지만, tcell v2.13.10 CellBuffer는 uniseg 기준 1칸으로 출력. 배치 시 한 칸씩 빈 공간 발생.
- 모든 텍스트 배치·정렬 너비를 tcell과 동일한 uniseg 기준으로 통일. 한글은 기존처럼 2칸 유지.
- 지폐를 굵은 상자 그리기 문자 `┏━┓┃┗┛`로, 게이지 경계를 `┃`로 변경. 채움은 연결된 `█` 12칸 유지.
- 한국어 너비 조건을 강제한 회귀 테스트에서 수정 전 지폐 2곳·게이지 3곳의 빈칸 실패를 재현했고, 수정 후 통과. 전체 24개 테스트와 go vet 통과.
- Windows v1.0.2 네이티브 실행 파일로 월급 입력·게임 시작 후 `┏━━━┓`가 공백 없이 출력되는 것을 확인. GUI 프로세스 실행도 확인했으나 UI 도구 창 목록에 나타나지 않아 실제 글꼴 스크린샷 검증은 수행하지 못함. Mac 실기기 실행은 미검증.
- 기존 문자 버전은 v1.0.1로 재빌드·패키징하고 --version과 패키지 구조 검증, Git v1.0.1 태그 생성. 이전 v1.2.0 배포 폴더는 실행 중 파일 보호를 위해 그대로 보관.

## v1.0.1 (기존 v1.2.0을 재지정) 문자 지폐와 게이지

- 작은 지폐는 `┌───┐ / │ ₩ │ / └───┘` 문자 그림으로 표시. 성과급은 더 넓은 금색 테두리와 `₩ +30m`으로 구분. 낙하·바닥 지폐 모두 픽셀 표현 제거.
- 세로 테두리 사이 12칸을 `█`로 채우는 게이지 적용. 한글 입금 안내는 바이트 수가 아닌 표시 열 너비로 오른쪽에 배치.
- 문자 지폐 높이와 성과급 클릭 영역, 바닥 도착 위치를 일치시킴.
- 전체 23개 테스트 및 `go vet ./...` 통과. 실제 렌더러 셀 스냅샷을 `artifacts/screens/v1.2.0/`에 생성해 시각 확인.
- Windows v1.2.0 EXE를 실제 터미널에서 실행해 급여 입력 후 문자 테두리 지폐와 ₩ 표시, 게이지를 확인.
- 배포 경로는 `dist/v1.2.0/`로 분리해 현재 실행 중인 이전 버전을 덮어쓰지 않음. Mac 실기기 검증·서명·공증은 미포함.

- Windows 실제 의사 터미널(80×24)에서 EXE 실행, 월급 3,600,000원 입력, 게임 시작, 기본급 증가 확인.

- 결과에서 Enter로 초기 화면 복귀 및 Esc 정상 종료 확인.

## 배포 검증 및 한계

- Windows x64 콘솔 EXE, Mac Intel/Apple Silicon용 Mach-O 교차 빌드.
- 두 Mac 아키텍처를 Universal 바이너리로 묶음. `.app` 실행기가 기본 Terminal에서 게임을 시작하도록 구성.
- `scripts/verify-packages.py`로 PE/Mach-O 헤더, 아키텍처, 파일 범위, 앱 진입점, LF 개행, ZIP 실행 권한, 원본과 ZIP 일치, SHA-256 검사.
- 독립 리뷰에서 발견한 Mac 절전 시계와 입력 재해석 문제 수정 후 회귀 테스트 통과.
- **Mac 실기기는 없으므로 Finder 더블클릭, Terminal의 실제 마우스 입력, Gatekeeper 통과는 미검증.** Developer ID 서명·공증 및 Windows 코드 서명 미포함. Mac에서 제한 없이 더블클릭 실행되는 상태까지 검증 완료했다고 주장하지 않음.
