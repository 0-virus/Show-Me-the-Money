# 검증 기록

날짜: 2026-11-06. 호스트: Windows x64. Go 1.27.3, tcell v2.13.10.

## 자동 검증

- `scripts/test.ps1 -Wasm`: 계산 모델 7개, 화면/입력/렌더링 8개 테스트 통과 (15개).
- `go vet ./...`: 통과.
- 월/연봉 환산, 5초 경계, 소수 금액 누적, 1조 원 입력, 18시 마감, 시계 역행, 중복 정산, 성과급 만료와 중복 수령 방지 검증.
- 초기→게임→결과→초기, 연봉 선택, 음수·소수·지수 입력 거부, 성과급 마우스 클릭, 버튼 클릭, 창 축소 중 자동 정산, 80×24 기본 크기에서 플레이 검증.
- 절전 시간 반영을 위해 모든 게임 시각에서 monotonic 부분을 제거하고 wall clock을 사용. 실제 Mac 절전 실행은 검증하지 못함.
- 변경 없는 화면은 터미널 셀을 다시 전송하지 않는 회귀 테스트 통과.
- 실제 렌더러의 셀을 이미지로 변환해 초기·게임·결과·작은 화면을 시각 검수. 파일은 `artifacts/screens/`에 보관.

## 네이티브 실행

- Windows EXE `--version`: `Money Copy 1.0.0` 정상 출력.
- Windows 실제 의사 터미널(80×24)에서 EXE 실행, 월급 3,600,000원 입력, 게임 시작, 기본급 증가 확인.
- 플레이 57초 시점 직접 종료: 완료된 55초치 급여 305원, 성과급 0원, 합계 305원 표시 확인.
- 결과에서 Enter로 초기 화면 복귀 및 Esc 정상 종료 확인.
- 최종 배포 EXE에서 truecolor 출력 확인. 마우스 시작 → 16초 플레이 → 마우스 종료로 기본급 83원 정산 → 마우스 처음으로 → Esc 종료까지 재확인. 성과급 클릭은 시뮬레이션 통합 테스트로 검증했으며 네이티브에서 3~7분을 기다려 수령하는 테스트는 실행하지 않음.
- 이 호스트는 일부 `*.test.exe` 실행을 Application Control로 차단하므로 계산·화면 테스트는 같은 Go 소스를 WebAssembly로 컴파일해 Node에서 실행함. 게임 EXE 본체는 실행 가능했음. 보안 설정은 변경하지 않음.

## 배포 검증 및 한계

- Windows x64 콘솔 EXE, Mac Intel/Apple Silicon용 Mach-O 교차 빌드.
- 두 Mac 아키텍처를 Universal 바이너리로 묶음. `.app` 실행기가 기본 Terminal에서 게임을 시작하도록 구성.
- `scripts/verify-packages.py`로 PE/Mach-O 헤더, 아키텍처, 파일 범위, 앱 진입점, LF 개행, ZIP 실행 권한, 원본과 ZIP 일치, SHA-256 검사.
- 독립 리뷰에서 발견한 Mac 절전 시계와 입력 재해석 문제 수정 후 회귀 테스트 통과.
- **Mac 실기기는 없으므로 Finder 더블클릭, Terminal의 실제 마우스 입력, Gatekeeper 통과는 미검증.** Developer ID 서명·공증 및 Windows 코드 서명 미포함. Mac에서 제한 없이 더블클릭 실행되는 상태까지 검증 완료했다고 주장하지 않음.
