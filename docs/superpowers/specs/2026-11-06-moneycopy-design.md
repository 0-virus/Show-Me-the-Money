# 가만히 있어도 돈이 복사가 되면 얼마나 좋을까

사용자가 요청한 실제 터미널 방치형 게임. 추가 설계 판단은 사용자 위임에 따라 진행한다.

## 설계
- Go + tcell v2의 실제 터미널 화면. Windows 단일 EXE, macOS Universal Mach-O 및 더블클릭용 앱 번들. 외부 런타임·네트워크 불필요.
- 월급/연봉(원)을 입력 → 게임 → 결과 → 초기 화면의 세 화면.
- 월급 = 연봉 / 12, 시급 = 월급 / (40 × 4.5). 1분마다 시급 / 60을 적립한다. 현실 시간과 동일한 속도로 수입이 쌓인다.
- 계산은 정수 분수로 보존하고 표시할 때 원 미만 절사하여 누적 반올림 오차를 피한다. 기본급 + 성과급의 표시 합계가 일치한다.
- 기기 현지 시각의 다음 오후 6시에 종료. 정확히 18시 이후 시작하면 다음 날 18시. 절전에서 돌아와도 마감까지만 적립, 성과급은 자동 수령하지 않는다.
- 검정/짙은 녹색 바탕, 민트색 타이포, 반각 블록 도트 지폐와 쌓이는 지폐더미. 금색 큰 지폐는 180~420초 균등 간격(평균 5분)으로 등장. 바닥 도착 전 클릭 시 시급의 절반(30분치 기본급) 지급, 중복 수령 방지.
- Enter 시작/돌아가기, Tab 월급/연봉 전환, Esc 게임 퇴근 확인, Ctrl+C 프로그램 종료. 버튼은 마우스 지원. 마우스 미지원 터미널용 Space 성과급 수령 대안.
- 작은 창에는 크기 안내, 창 변경 시 배치 재계산. 최대 입력 1조 원, 음수·0·잘못된 입력 거부.
- Windows 64bit, Mac Intel/Apple Silicon 번들을 별도 디렉토리와 ZIP으로 제공. Mac 실행 권한을 ZIP 메타데이터에 보존한다.

## 선택 근거
Electron 터미널풍 GUI는 배포 크기가 크고 실제 터미널 요구와 다르다. Python은 OS별 패키징 호스트 의존성이 크다. Go/tcell은 마우스·유니코드 지원과 순수 Go 교차 컴파일에 적합하다.

## 검증 범위
규칙 단위 테스트, tcell 시뮬레이션으로 입력/클릭/리사이즈 통합 테스트, Windows 배포 EXE 실제 터미널 구동. Mac 바이너리 구조·아키텍처·ZIP 권한 검증. Mac 실기기나 서명 인증서가 제공되지 않은 경우 실기기 실행 및 공증을 완료했다고 주장하지 않는다.

## v1.1.0 플레이 피드백
지폐를 가로·세로 각각 50% 축소. 기본급은 1분마다 1분치 지급, 성과급은 30분치 유지. ASCII 고정 폭 게이지 오른쪽에 입금 안내. 초기·게임 Esc는 확인창(기본 아니요), 확인 중 시계와 자동 정산 유지. 요청한 문구 교체/삭제 및 금요일 다음 주/나머지 내일 인사 적용.
