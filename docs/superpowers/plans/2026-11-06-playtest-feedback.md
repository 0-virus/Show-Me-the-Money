# 플레이 피드백 반영

사용자 승인 범위: 지폐 양축 50% 축소, 게이지 오른쪽 입금 안내, 1분마다 1분치 기본급, 요청한 문구 교체/삭제, 초기·게임 화면 Esc 확인창, 요일별 결과 인사, 실행 파일 재배포 및 단계별 커밋.

- [ ] 계산 테스트를 60초 경계·여러 분 지연·18시 마감에 맞춰 변경하고 실패 확인 → 공유 입금 주기 적용.
- [ ] 초기/게임 Esc 확인·취소·확정, 확인 중 자동 마감, 작은 지폐 히트박스 및 게이지 비중첩 테스트 → 입력·화면 수정.
- [ ] 화면 셀 이미지 검수, 전체 테스트/vet, Windows 실행 파일에서 실제 조작 확인.
- [ ] Windows 및 Universal Mac 빌드, 패키지 검사, README·검증 기록 갱신, 커밋.

판단: 확인창은 기본값 '아니요', Esc로 취소, 방향키/Tab·Enter 또는 마우스로 선택. 확인 중 시계는 계속 흐르며 18시에는 자동 정산한다. 종료 버튼/Q도 같은 확인창을 사용한다. 결과 인사는 시작일이 금요일이면 '고생하셨어요, 다음 주에 봐요!', 나머지 요일이면 '고생하셨어요, 내일 봐요!'. 마지막 입금 이후 1분 미만의 미적립 구간은 기존 방식대로 지급하지 않는다.
