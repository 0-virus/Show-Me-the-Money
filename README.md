# 가만히 있어도 돈이 복사가 되면 얼마나 좋을까

현실과 같은 속도로 급여가 쌓이는, 설치 없이 즐기는 터미널 방치형 게임.

## npm으로 바로 실행

Node.js 20 이상과 npm이 설치되어 있다면 PowerShell 또는 터미널에서 아래 명령을 실행하세요. 게임 ZIP을 따로 내려받거나 Go·Python을 설치할 필요는 없습니다.

```sh
npx @halmasy1/moneycopy@latest
```

처음 실행할 때 패키지 설치 여부를 물으면 `y`를 입력하세요. 게임을 자동으로 다운로드해 npm 캐시에 저장한 뒤 시작합니다. 별도 수동 설치는 필요 없지만, 최초 다운로드와 `@latest` 버전 확인에는 인터넷 연결이 필요합니다.

게임이 열리면 월급 또는 연봉을 선택하고 금액을 입력한 뒤 Enter를 누르세요. 플레이 중 Esc를 누르면 퇴근 확인 후 결과를 볼 수 있습니다.

개발 소스 폴더에서도 공개 배포본을 실행하도록 `@latest`를 명시합니다. 이를 생략하면 npm이 현재 프로젝트를 같은 이름의 로컬 패키지로 선택해 Windows에서 `moneycopy` 명령을 찾지 못할 수 있습니다.

계속 설치해 두고 실행하려면:

```sh
npm install -g @halmasy1/moneycopy
moneycopy
```

지원 환경은 Windows x64, macOS 13 이상 Intel/Apple Silicon입니다. OS별 실행 파일이 패키지에 함께 들어 있으며 실행기가 자동 선택합니다. Linux 및 Windows ARM64용 Node는 지원하지 않습니다. Mac 실기기 실행은 미검증입니다.

## 실행 파일로 플레이

- **Windows 10/11 (64비트)**: `MoneyCopy-Windows-v1.0.3.zip`을 풀고 `Windows/MoneyCopy.exe`를 실행합니다.
- **macOS 13 이상 (Intel / Apple Silicon)**: **Mac에서** `MoneyCopy-macOS-v1.0.3.zip`을 풀고 `macOS/MoneyCopy.app`을 실행합니다. 기본 Terminal 앱에서 게임이 열립니다. ZIP에 실행 권한이 보존되어 있으므로 Windows에서 압축을 푼 폴더를 복사하는 대신 ZIP 자체를 Mac에 옮겨 주세요.
- 인터넷, Go, Python, 별도 게임 런타임 설치는 필요하지 않습니다. 폴더 어디에 두어도 실행할 수 있습니다.
- 권장 크기 110열 × 36행, 최소 76열 × 24행. 한글을 표시할 수 있는 터미널 글꼴을 사용하세요.
- 급여는 저장하거나 외부에 전송하지 않습니다. 창을 닫으면 이번 게임 기록은 사라집니다.

개인 배포용으로 Windows 서명 및 Apple Developer ID 서명·공증은 포함하지 않았습니다. 운영체제나 회사 정책이 실행을 차단하는 경우 관리자 확인이 필요합니다. 보안 설정을 바꾸는 절차는 게임에 포함하지 않습니다.

## 플레이

1. 월급 또는 연봉을 선택하고 **원 단위 숫자**를 입력합니다. 쉼표도 사용할 수 있습니다.
2. `돈 복사 시작`을 클릭하거나 Enter를 누릅니다.
3. 작은 초록 지폐는 자동으로 떨어집니다. 금색 큰 지폐가 보이면 **10초 안에 클릭**하세요. 성과급이 지급됩니다.
4. 오후 6시에 자동 정산하며, `게임 종료` 버튼이나 Esc로 퇴근 확인 후 정산합니다. `다시 출근하기...`를 누르면 새로 시작합니다.

| 조작 | 기능 |
|---|---|
| Tab | 초기 화면에서 월급/연봉 전환 |
| 숫자 / Backspace / Ctrl+U | 급여 입력 / 한 글자 삭제 / 입력 지우기 |
| Enter | 시작 / 결과에서 처음으로 |
| 마우스 왼쪽 클릭 | 버튼 및 금색 지폐 선택 |
| Space | 마우스 미지원 터미널에서 떠 있는 성과급 수령 |
| Esc / Q | 게임 중 퇴근 확인 (초기 화면 Esc는 반차 확인, 결과 화면 Esc는 종료) |
| 확인창: Tab / 방향키 / Enter / Esc | 선택 변경 / 선택 확정 / 취소 (기본 선택은 아니요) |
| Ctrl+C | 프로그램 닫기 |

터미널 설정에 따라 Shift+클릭은 게임 대신 텍스트 선택으로 동작할 수 있습니다. 일반 클릭을 사용하세요.

## 계산 규칙

- 월 근로시간 = 주 40시간 × 4.5주 = **180시간**
- 연봉 입력 시 월급 = 연봉 ÷ 12
- 시급 = 월급 ÷ 180
- **1분마다 시급 ÷ 60**을 기본급에 누적
- 성과급 1회 = **시급 × 0.5 (30분치 급여)**
- 성과급 출현 간격은 180~420초의 무작위 값으로 평균 약 5분입니다.
- 계산 중 소수 금액을 유지하고 표시할 때 원 미만을 절사합니다. 합계는 화면에 표시한 기본급 + 성과급입니다. 입금 직전 종료한 마지막 1분 미만은 적립하지 않습니다.
- 기기 현지 시각으로 다음 오후 6시에 자동 정산합니다. 18시 이후 시작하면 다음 날 18시에 정산합니다.
- 실행 중 절전 후 복귀하면 마감 시각까지 완료된 1분 구간을 반영합니다. 지난 성과급은 자동 지급되지 않습니다. 프로그램을 닫은 동안은 적립하지 않습니다.

예: 월급 3,600,000원 → 시급 20,000원 → 1분 약 333.33원, 1시간 20,000원, 성과급 10,000원.

종료 확인창이 열린 동안에도 시간은 계속 흐릅니다. 결과 인사는 게임 시작일이 금요일이면 “고생하셨어요, 다음 주에 봐요!”, 나머지 요일이면 “고생하셨어요, 내일 봐요!”입니다.

## 개발

Go 1.24 이상과 Python 3(배포 패키징용)을 사용합니다. 의존성은 go.mod/go.sum에 고정되어 있습니다.

```powershell
go test ./...
go vet ./...
go run ./cmd/moneycopy
./scripts/build.ps1
```

호스트가 생성된 테스트 EXE를 차단할 경우, Node.js를 사용해 동일한 Go 테스트를 WebAssembly로 실행할 수 있습니다. 네이티브 실행 검증을 대체했다고 간주하지 않습니다.

```powershell
./scripts/test.ps1 -Wasm
./scripts/build.ps1 -SkipTests
```

출력: `dist/v1.0.3/Windows`, `dist/v1.0.3/macOS`, 같은 버전 폴더의 OS별 ZIP 및 `SHA256SUMS.txt`.
화면 셀 스냅샷은 `MONEYCOPY_SNAPSHOTS` 환경 변수로 경로를 지정하면 테스트가 생성합니다. `scripts/render-snapshots.py`는 개발용 Pillow로 이를 PNG로 그립니다.

테스트 범위와 실제 실행 확인 내용은 `docs/verification.md`에 기록합니다.

## npm 패키지 만들기 및 게시

패키지 이름은 `@halmasy1/moneycopy`, 명령은 `moneycopy`입니다. 준비된 `dist/v1.0.3/` 네이티브 배포 파일을 사용합니다. 새 게임 버전은 Go의 version, scripts/package.py의 VERSION, package.json의 version을 함께 올린 뒤 네이티브 빌드를 다시 만듭니다.

개발 환경에는 Node.js, npm, Python 3이 필요하며, 네이티브 재빌드 시 Go도 필요합니다. 저장소 루트에서:

```sh
npm test
npm run pack:release
python scripts/verify-npm.py
```

`prepack`은 기존 ZIP 무결성과 버전을 확인한 뒤 `native/`와 의존성 라이선스 파일을 생성합니다. `pack:release`는 npm 압축 파일의 Mac 실행 권한을 보존하도록 마무리하고 실제 파일 목록·바이너리·실행 권한을 검증합니다. npm 설치 시 실행하는 빌드/다운로드 스크립트는 없습니다.

`pack:release`는 로컬 `.tgz`를 만들 뿐 게시하지 않습니다. 폴더에서 바로 `npm publish`를 실행하면 Mac 실행 권한이 다시 빠질 수 있어 안내 후 중단합니다. 검증한 파일을 공개 게시하려면 npm 계정 `halmasy1`으로 로그인한 뒤 다음을 실행합니다.

```sh
npm login
npm whoami
npm publish ./dist/v1.0.3/halmasy1-moneycopy-1.0.3.tgz --access public
```

로그인 계정의 2단계 인증 안내에 따라 인증을 완료하세요. 패키지 이름과 버전이 이미 게시되어 있다면 같은 버전을 덮어쓸 수 없으므로 버전을 올려야 합니다. 프로젝트 자체 라이선스는 별도로 지정되지 않아 `UNLICENSED`이며, 포함된 제삼자 코드의 라이선스는 `THIRD-PARTY-LICENSES.txt`에 포함됩니다.
